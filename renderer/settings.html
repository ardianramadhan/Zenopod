Jadwal

Fokus

Pomodoro: fokus, lalu istirahat sebentar. Mulai dari tab Fokus di panel Zenopod.

Istirahat mulai otomatis
Begitu fokus selesai, timer istirahat langsung berjalan.
Tahan notifikasi saat fokus
Notifikasi tetap masuk daftar, tapi kartunya tidak muncul. Pengingat dan izin Claude tetap muncul.

Claude Code

Maskot ikut berpikir saat Claude bekerja, senang saat selesai, dan memanggilmu saat Claude butuh jawaban.

Memeriksa…

Hook lain (mis. Coucou) tidak diubah. Salinan settings.json disimpan sebagai settings.json.kapsul-backup setiap kali dipasang atau dilepas. Berlaku untuk sesi Claude Code yang dimulai sesudahnya.

Jawab izin dari Zenopod
Saat Claude minta izin, muncul tombol Izinkan / Tolak / Di terminal. Tidak dijawab 90 detik = dialog biasa muncul di terminal.
Kartu Claude
Tampilkan pesan terakhir Claude saat selesai dan saat butuh jawabanmu.

Dev
